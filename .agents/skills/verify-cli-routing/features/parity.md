# Typed command parity

## Sub-features

The add member of the prepared-command union, unchanged printing, success/refusal
History, all-table comparison, and negative comparison controls.

## How to get to it (user POV)

No production command uses this endpoint in slice 1. Later add routing uses the
same prepared input and executeAdd result already verified by this companion.

## Driving it with the compiled driver

Run Launch. The deterministic compiled companion runs direct and through the
production HttpApi on clones restored to the same pathname. Compare stdout,
stderr, exits and every logical table for JSON, Markdown and table output.

## Gotchas

Test-only deterministic Date/UUID replacement is confined to the companion entry
point. Repeated-denial parity remains gated on the separately reviewed durable
Authentication.record fix. Do not enable production routing from this proof.
