# Task Dependencies

The existing validated Request/Reply and shared HttpApi client carry graph,
Profile-wide candidate search, immediate depend/undepend, batch-depend and Delete
preview/confirmation. Every request keeps the dynamic credential getter.

Run from the repository root with an existing Chrome executable, frozen pnpm
packages and a fresh repo-relative evidence directory:

```sh
export TODO_HEADLESS_CHROMIUM='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
sh apps/electron/scripts/guarded-run.sh bun apps/electron/scripts/prepare-dag-proof.ts
sh apps/electron/scripts/guarded-run.sh pnpm --filter @todo/electron test
sh apps/electron/scripts/guarded-run.sh /usr/bin/lockf -k /tmp/todo-search-electron.lock bun apps/electron/scripts/verify-dependencies-offscreen.ts docs/evidence/task-dag/electron-new
```

The prepare helper guards each compiler and caches CLI/server/seed by source hash
and committed build SHA in ignored `.scratch/bin`. Final proof must compile at the
final committed source. The renderer drive uses production components, a fresh
scratch HOME/database, real compiled HTTP and SSE, and an existing headless Chrome.
It never downloads a browser or touches native credentials. Capture manifests
validate every referenced file, including symlink escape checks, before writing.

The driver covers row badges, Ready/Blocked filters, server order, both immediate
picker directions, checked links under search, pending states, real refusals,
initial creation/follow-up, Delete, batch, nested Import projection, graph and list
drag/menu/keyboard paths. Controlled typed reports exercise errors that cannot all
be generated by one valid server operation; results label that boundary. Literal
assertions and reloads establish behavior. Read every final image before delivery.
Until result.json and the unit report explicitly record complete coverage, the
recipe remains `DAG_INTERMEDIATE_PARTIAL`. It cannot replace either full end suite.

Search recovery uses `dependency-search-error` separately from the preserved
mutation `dependency-error`. `verify-dependency-search-recovery.ts` drives valid
controlled public 422 replies through the actual HttpApi client, with ordinary
200 Task data read from the compiled scratch server. Narrower success and clear
remove only the search notice; mutation witnesses, Conflict/Reload and a reviewed
batch report survive. Delayed older errors are awaited through SDK delivery before
asserting that they cannot republish. The fixture does not exhaust a live search
budget. Run `dependency-search-recovery.test.ts` for the literal controller controls.

Missing graph roots clear stale diagram/search display data. Graph and Delete
errors preserve their actual exit pair and offer deliberate Find Task by id.
Batch and nested Import recovery can open captured blockers or preselect the
specified DONE Task in the existing follow-up flow. Quick-add captures wait for
the real parsed preview, show whole initial chips and reach the last wrapped chip
without moving the fixed footer. Initial Series selection affects only the first
Occurrence; a public reload must prove the successor inherited no edge.

Every Task Delete entry shares the server-preview controller and dialog. Confirm
uses the reviewed preview request Version and fingerprint even with no edges.
Changed or changed-to-empty previews require another explicit confirmation. Cancel
has initial focus; long lists scroll while counted headers and actions stay visible.
Batch preview has separate explicit per-item Apply and Conflict Reload, with no
blind Version advancement after refused items. Immediate picker writes never
advance an unsaved editor's expected Version.

Command/Control-Shift-K and the existing menu/editor entry open the same picker.
Plain Command-K stays free. Search initially receives focus; Arrow keys move among
choices, Space toggles and Close returns focus. A list SOURCE dropped on TARGET
means TARGET depends on SOURCE. Visible target metadata says `Will depend on
<source>` or `Already depends on <source>`; the accessible value names both Tasks.
No row may move during hover/pending, and the hint must not overlap the title.
Self/foreign/already-linked drops send no write. Native key/drag dispatch is unproven.

Graph mode reuses the canonical local browser resource; app state owns camera,
selection, focus and expansion. Compact opens List; full window shows diagram and
list beside it. Pele failure retains an accessible list and Retry. Copy as Mermaid
must send exact server export text through the validated host request; this alone
does not prove the native clipboard. Canonical protocol/resource/lock changes
require a fresh committed L1/coordinator handoff before S consumes any bytes.

`verify-dependency-readiness.ts` adds open/snoozed Ready and Blocked, linked
terminal Tasks without badges, combined filters and whole-Profile server ordering.
Snoozed setup uses the existing authenticated TaskCreated v1 fixture boundary on
the fresh scratch database; no public Snooze command is invented. The driver
checks cached binary hashes, the CLI's embedded version and the compiled server's
health identity before renderer proof.

`verify-dependency-graphs.ts` asserts server-reported converging/diverging/mixed
trees and a DAG, shared-ancestor Energy pruning, unknown Energy last, terminal
Lightest next, a 52-Task group, expansion and real SSE camera/focus preservation.
The app distinguishes fitted and manual cameras. Frame resize coalesces through
ResizeObserver and animation-frame layout, refits only an automatic camera, and
preserves a person's pan/zoom until Reset. Assert new-frame centring, unchanged
manual viewport on Compact/full/window resize, and centred Reset in Chromium.

Repeated graph Tasks use fixed section tokens: shown, depends-on, blocks,
lightest-next, starts-at, ends-at, ancestors, descendants. Tasks in diagram retain
`dependency-graph-task-<id>` and `dependency-graph-expand-<id>`. Other rows use
`dependency-graph-related-<section>-<id>` and
`dependency-graph-expand-related-<section>-<id>`. All row menus use
`dependency-graph-actions-<section>-<id>`. Host identities remain full Task ids.
The driver opens Graph details, asserts unique identities for repeated Tasks and
checks that a section menu routes to the selected Task's fresh root report.

The complete suite is `apps/electron/scripts/verify-design-all.ts`; its inventory
must list all standalone offscreen files and unsigned helper modes. A failed,
missing or partial recipe keeps the aggregate nonzero. See `verify-design-all.md`
for exact arguments, guards, baseline identities and native HOLD. Full Mac proof
uses its plain Python helper through `scripts/swift-slot.sh`, all focused selectors
unset. Preserve the known main Import assertions and compare exact fixtures/values.
Native safeStorage, Session restoration, notifications, VoiceOver and signed app
launch remain held and unproven. The unit report names actual source/proof SHAs,
commands/exits, manifests, cleanup and every remaining boundary.
