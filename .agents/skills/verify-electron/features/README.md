F10 adds Delete Profile at the end of the Profile switcher menu, after a separator. The compiled host drive
checks the named count, explicit Delete Tasks too step, successful switch and
external CLI deletion through SSE. It captures profile-delete-empty, profile-delete-refusal and
profile-delete-tasks in light and dark. Native storage remains on HOLD.

The final confirmation explains recovery through Settings > Snapshots. Named
notices identify the deleted Profile. Open the Profile button, then select
`Delete "<name>"…`; it is unavailable in the last Profile, offline or editing.
