The driver imports production response schemas and asserts literal responses.
It uses a private HOME, database and vault and stops its recorded server.

Read actions.json for real exits and HTTP statuses. Edge no-ops leave Tasks,
edges, History, checkpoints and Snapshot files unchanged despite stale expected
Versions. Real stale edits return exit 4. Same-Profile and self/cycle checks,
redundant stored edges and exact 9/13/14 counts use the public commands.

cases. graph-public.json includes the changed-to-empty fingerprint evidence,
terminal Ready/Blocked exclusion, topological/lightest ordering and a 105-Task
cycle witness returned intact by both CLI and HTTP.

original row order, Version-1 initial edges, diamond energy 10, failed adoption,
per-Task cycle refusal and independent success. A blocked import must preserve
current_version and every field of details.dependency_error through encoding.

depends_on and response-only graph/search metadata. The real sync command
preserves surrounding note text and writes stable block links plus Mermaid.

dependency replacement, exact old no-dependency output, escaped labels,
outside-projection links and both replay modes. Client feature UI is unclaimed.
