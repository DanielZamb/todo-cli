# Todo Verification

This separate Xcode project builds the production Mac Task screens with a
memory-only Session store and scratch startup guards. It is never an installed
product. See ADR-0021 and the verify-macos-real-app skill.

Build through `scripts/swift-slot.sh` with signing disabled and automatic
package resolution disabled. The proof helper copies the production resolved
package file into the ignored workspace location before building. Its pins
must remain byte-identical to the production pins.

The checked-in project is generated by `ruby apps/macos/VerificationApp/add-target.rb`.
The generator reads production target membership and excludes TodoApp,
SessionVault, ServerLifecycle and ServerSettingsView. Re-run it when production
source membership changes, and audit the result before launching.

CredentialSymbols.inc names exported Security credential APIs from the macOS
SDK. Each resolves to a fatal handler through a separately embedded dylib.
The application itself imports no credential API. TrapProbe verifies pointer
identity before calling a trapped symbol, so failed interception never calls
the original. Extending credential use requires updating and proving the trap
list and artifact audit first.

The runtime sandbox denies owner-home file access except the test app bundle,
allows scratch files, limits outbound network access to the scratch server
port and denies process execution. A separate Foundation probe uses only
run-owned sentinel files to prove its deny rules before a visible launch.

The runtime entry requires a private JSON manifest with root, home, serverURL,
serverPath, cliPath, serverSHA256, cliSHA256, serverPID, database, contract,
build, profile and session. Manifests contain a scratch Session and stay only
in the private scratch root. No manifest, dump or capture is tracked.

V01 has read-only accessibility proof. V02 real input and measurement is held
until the coordinator releases it after review.
