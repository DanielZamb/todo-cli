Diagrams are frames in one Excalidraw scene, [diagrams/todo.excalidraw](diagrams/todo.excalidraw),
generated by `diagrams/generate.mjs`. `diagrams/render.sh` regenerates the
scene and exports one PNG per frame.

Verification recipes are `.agents/skills/verify-*`. Evidence directories are
local and gitignored. Track notes in [decisions/](decisions/) are implementation
history from the Effect port, not architecture records.
