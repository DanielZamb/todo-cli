# HttpApi with OpenAPI is the single client contract

The server exposes one Effect `HttpApi` definition. The Electron client derives a typed client from it directly. The SwiftUI client uses a Swift client generated by `swift-openapi-generator` from the OpenAPI document the API emits. We rejected Effect RPC: its wire format only exists as TypeScript schemas, so Swift would have had to reimplement it by hand. A second protocol just for Electron would split the contract.
